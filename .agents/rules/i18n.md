# Localization and Translation Rules (i18n)

Session Sniffer supports 33 languages: English (`en`, the canonical source language) plus 32 JSON translation catalogs in `resources/translations/<lang>.json` defined by `SUPPORTED_LANGUAGES` in `src/session_sniffer/i18n.py`:

`ar`, `bg`, `ca`, `cs`, `da`, `de`, `es`, `fa`, `fi`, `fr`, `gd`, `he`, `hr`, `hu`, `it`, `ja`, `ka`, `kk`, `ko`, `lg`, `lv`, `nl`, `nn`, `pl`, `pt-BR`, `ru`, `sk`, `sv`, `tr`, `uk`, `zh-CN`, `zh-TW` (with `ar`, `fa`, and `he` as right-to-left locales in `RTL_LANGUAGE_CODES`).

**Never consider a feature, UI change, or setting change complete until all 32 `resources/translations/*.json` catalogs are updated in the same task.**

## Wrapping User-Facing Text in Python

* Wrap every user-facing string in `tr('...')` or `tr_plural('...', '...', count, ...)` from `session_sniffer.i18n`:
  * window/dialog titles, tab titles, group box titles, labels, checkboxes, buttons, placeholders, status bar messages, tooltips, context menus, tray menus, message boxes, desktop/toast notifications, user-facing validation/error messages, and Embedded Web Server strings (`get_web_panel_i18n()`).
* Always pass **literal canonical English templates** with named `{placeholder}` keyword arguments (`tr('Shortcut: {shortcut}', shortcut=text)`). Never pass pre-formatted `f'...'` strings into `tr()`, because runtime values will miss catalog lookup.
* For count-dependent user-facing text, use `tr_plural('{count} player connected', '{count} players connected', count)` (`count` is automatically passed as `{count}` alongside any extra keyword arguments). Static titles and menu action labels remain fixed strings (e.g. `tr('Add Username(s)')`).
* **Implicitly translated declarative metadata** (translated at render time via `tr()`, so their English literals are canonical catalog keys):
  * `SettingMeta` fields in `src/session_sniffer/settings/metadata.py` and `src/session_sniffer/settings/_metadata_gtav.py`: `category`, `group`, `subgroup`, `display_label`, `tooltip`, `suffix`, `special_value_text`, and `allowed_values` entries when `display_labels` is omitted (or `display_labels` values when provided).
  * `ThemeColorToken` fields in `src/session_sniffer/models/themes.py`: `label`, `category` (and `THEME_TOKEN_CATEGORIES`), and `description`.
  * Session table column headers/tooltips and static spec tuples passed into `tr()` or `live_language.py` helpers.
* **Do NOT translate**:
  * internal `settings.json` keys, enum/protocol identifiers, file/folder paths, URLs, CLI/Win32/POSIX command syntax, or packet/network wire values;
  * developer log messages (`logger.debug`, `logger.info`, `logger.warning`, `logger.error`, `logger.exception`);
  * native language names in `SUPPORTED_LANGUAGES`.

## Live Language Switching and RTL Compatibility

Users can preview and switch languages in real time without restarting (`src/session_sniffer/guis/live_language.py`):

* Reuse the helpers in `src/session_sniffer/guis/live_language.py` when building widgets:
  * `set_i18n_colon_label(label, 'Label Text')` for form labels rendered with a trailing colon (`:`).
  * `set_table_headers(table, headers, tooltips)` and `set_tree_headers(tree, headers, tooltips)` for `QTableWidget` / `QTreeWidget` headers so `CANONICAL_HEADER_ROLE` and `CANONICAL_HEADER_TOOLTIP_ROLE` are stored for live retranslation.
  * `add_i18n_menu_actions(parent, menu, icons_dir, specs, records)` for menus whose actions need live retranslation.
* Escape literal `&` as `&&` on `QGroupBox` titles (`.replace('&', '&&')`) and buttons/checkboxes where `&` is not a keyboard mnemonic, matching `live_language.py`'s mnemonic-preserving retranslation logic.
* Whenever a widget displays **interpolated, compound, or state-dependent** translated text or tooltips (such as counts, keybind hints in tooltips, status banners, combobox item labels with `userData`, or rich-text HTML blocks built with placeholders), register a refresh callback via `register_language_refresh(owner_qobject, refresh_callback)` so live language changes immediately re-render it.
* Preserve RTL layout compatibility (`ar`, `fa`, `he`): rely on Qt logical layouts (`QHBoxLayout`, `QVBoxLayout`, `QFormLayout`, `QGridLayout`) and `Qt.AlignmentFlag.AlignLeading` / `AlignTrailing` rather than hardcoded left/right pixel positioning when directional mirroring applies.

## Maintaining `resources/translations/*.json`

Whenever any canonical user-facing string or declarative metadata text is **added, modified, renamed, or removed**:

1. **Update all 32 catalogs in `resources/translations/*.json` in the same task**:
   * Add natural, domain-accurate translations (matching each locale's existing Session Sniffer terminology for terms such as `Capture`, `Solo Public Session`, `Player Resolver`, `Looky System`, `Connected`, `Disconnected`, etc.) to `"messages"` or `"plurals"` in every `<lang>.json`.
   * Delete obsolete or renamed English keys from **all 32** catalogs outright (`No Backward Compatibility` in `core.md`). Never leave orphaned keys behind.
2. **Preserve placeholders and markup**:
   * Every translated string must contain the **exact same `{placeholder}` names and format specifiers** (such as `{count}`, `{count:,}`, `{jitter:.2f}`, `{ip}`, `{shortcut}`) and matching inline HTML tags (`<b>`, `<i>`, `<br>`, `<code>`, `<a href="...">`) as the canonical English key.
3. **Maintain 1-to-1 unique `"messages"` values per catalog**:
   * `lookup_canonical_message()` in `src/session_sniffer/i18n.py` builds a reverse map (`translated_text -> canonical_english_key`) so `live_language.py` can retranslate live widgets across language switches.
   * **No two keys in the same `<lang>.json` `"messages"` dictionary may have the exact same translated string value.** Disambiguate colliding translations naturally using context when needed.
4. **Provide all required CLDR plural categories in `"plurals"`** (keyed by the canonical English singular string, matching `_PLURAL_SELECTORS` in `src/session_sniffer/i18n.py`):
   * `ja`, `ko`, `zh-CN`, `zh-TW`: `other`
   * `ar`: `zero`, `one`, `two`, `few`, `many`, `other`
   * `he`: `one`, `two`, `many`, `other`
   * `gd`: `one`, `two`, `few`, `other`
   * `cs`, `hr`, `sk`: `one`, `few`, `other`
   * `pl`, `ru`, `uk`: `one`, `few`, `many`, `other`
   * `lv`: `zero`, `one`, `other`
   * All other supported languages (`bg`, `ca`, `da`, `de`, `es`, `fa`, `fi`, `fr`, `hu`, `it`, `ka`, `kk`, `lg`, `nl`, `nn`, `pt-BR`, `sv`, `tr`): `one`, `other`
5. **Formatting and Line Endings**:
   * Keep `"messages"` and `"plurals"` sorted by canonical English key, formatted as UTF-8 JSON (`ensure_ascii=False`, `indent=2`) with a trailing newline and **CRLF (`\r\n`)** line endings across all 32 files.
6. **Website Preview Sync**:
   * Whenever any shared desktop UI string, theme token/name, or supported language metadata used by the `website/` live preview is added, renamed, or removed, update `SHARED_APP_MESSAGE_KEYS` / `SHARED_APP_PLURAL_SINGULAR_KEYS` in `website/sync_assets.py` and run `python website/sync_assets.py` in the same task (see `website-parity.md`).
