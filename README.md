## 📝 Description

**Session Sniffer** is a powerful packet sniffer (also known as an IP sniffer/puller) designed specifically for Peer-To-Peer (P2P) video games on PC and consoles (PlayStation and Xbox). It helps you monitor session activity, such as:
- Players currently in your session.
- Players joining your session.
- Players who have left or rejoined your session.

### 🔑 Key Features

- **Free & Open Source**: Completely free to use, unlike other similar software.
- **No Mods Required**: Works without mods, no risk of banning.
- **Advanced Options**: Configuration files for deep customization.
- **Game Server Scanning**: Includes a setting to scan for game servers.
- **Session Logging**: Save session data and logs for future analysis.
- **IP Protection**: Warns and protects against specific user IPs.

## 🔐 About Usernames Decryption/Resolving

Session Sniffer supports resolving and displaying player usernames through several methods:

- **PlayStation 3 (PS3)**: Direct packet payload extraction via the built-in **PS3 Name Resolver** setting. Note: This works only on supported PS3 games that broadcast unencrypted PSN usernames in packet payloads (see the **Username Resolving** column in the [Officially Tested and Supported P2P Video Games](#-officially-tested-and-supported-p2p-video-games) table for supported titles).
- **GTA Online (PC) Mod Menus**: Automatic username logging via these Lua plugins:
  - [Session Sniffer Cherax Lua Plugin](https://github.com/BUZZARDGTA/Session_Sniffer-plugin-Cherax-Lua)
  - [Session Sniffer Lexis Lua Plugin](https://github.com/BUZZARDGTA/Session_Sniffer-plugin-Lexis-Lua)
  - [Session Sniffer Stand Lua Plugin](https://github.com/BUZZARDGTA/Session_Sniffer-plugin-Stand-Lua)
- **GTA Online (PC) Looky System**: Cloud-based username resolving via [**Looky System**](https://looky-gta.cc/) (see [Looky System Configuration](https://github.com/BUZZARDGTA/Session-Sniffer/wiki/Configuration-Guide#looky-system-configuration)).
- **UserIP INI Databases**: Manual assignment of custom usernames to IP addresses using [UserIP INI databases Configuration](https://github.com/BUZZARDGTA/Session-Sniffer/wiki/Configuration-Guide#userip-ini-databases-configuration) files.

> _Note_: On current-gen consoles (PS4/PS5, Xbox One/Series X|S) and modern PC games, peer-to-peer network packets no longer expose unencrypted player usernames as this functionality has been patched on modern platforms. Packet-based automatic username extraction is therefore only possible on supported legacy console titles.
