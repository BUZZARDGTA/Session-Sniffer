Frequently Asked Questions

Is Session Sniffer safe to use? Can it get me banned?

Session Sniffer is 100% external — it passively reads network packets through standard capture drivers (Npcap / libpcap / BPF) and never injects into or modifies game files or memory. There is zero risk of an anti-cheat ban, and all source code is publicly auditable on GitHub under GPLv3.

Why does my antivirus flag Session_Sniffer.exe? Is it safe?

Yes — Session Sniffer is safe to run. Some antivirus software flags standalone executables as malware because they are compiled from Python using PyInstaller, which frequently triggers generic false-positive detections even on harmless apps.

The entire source code is open-source and publicly available on GitHub. If you are familiar with Python, you can also run Session Sniffer directly from source, which usually avoids antivirus detections.

In addition, release builds are compiled automatically via GitHub Actions and uploaded by the GitHub Actions bot, so you can review both the build workflow and every build run publicly.

Why is the Session_Sniffer.exe file so large?

Session Sniffer bundles Python and all required Python dependencies into a single standalone executable so the app works out of the box without requiring you to install anything manually.

That self-contained bundle includes the libraries needed for packet scanning, the PySide6 GUI, data handling, themes, translations, and other internal features — which is the main reason the executable file size is relatively large.

How do I install and set up Session Sniffer?
  1. Download the latest Session_Sniffer.exe for Windows (or the Linux / macOS standalone binary from the Download section above).
  2. Run Session_Sniffer.exe.
  3. If prompted on Windows, install Npcap — it is required for network packet capture. On Linux, install libpcap and grant capture capabilities (cap_net_raw); on macOS, grant /dev/bpf* read permissions as shown in the Installation Guide.
  4. Select the network interface you want to sniff from and click Start Sniffing.

How do I scan a PlayStation or Xbox console (Ethernet or Wi-Fi Hotspot)?
  1. Share your PC internet connection with the console
    • Ethernet Cable: Connect an Ethernet cable between your PC and the console and share your PC's internet connection (see the video tutorial below).
    • Wi-Fi Hotspot: Use Session Sniffer's built-in Hotspot & Connection Sharing (Capture → Hotspot & Sharing) or Windows Settings "Mobile hotspot" to share your PC's internet connection wirelessly.
  2. Connect the console to the shared network

    Disconnect your PlayStation or Xbox from its current internet connection, then connect it to the Wi-Fi hotspot or Ethernet connection you just shared from your PC.

  3. Launch Session Sniffer and select the Neighbour interface

    Open Session Sniffer and, in the Capture Network Interface Selection window, look for an entry labeled Neighbour in the Type column. Check the Vendor Name column (Microsoft Corporation for Xbox, or Sony Interactive Entertainment Inc. for PlayStation) — or cross-reference the IP Address and MAC Address with your console's network settings — then click Start Sniffing.

How do I scan using ARP Spoofing (PlayStation, Xbox, smartphone…)?
  1. Open the Capture Network Interface Selection screen

    From the toolbar, go to Capture → Change Interface — or open Settings → General, disable Auto Connect, and restart Session Sniffer.

  2. Enable ARP Spoofing

    Check Enable ARP Spoofing in the bottom-right corner of the window.

  3. Refresh the ARP table

    Click Refresh ARP Table in the bottom-left corner of the window. This wakes up devices on your local network so Session Sniffer can identify PlayStation, Xbox, smartphones, and other LAN devices.

  4. Choose your device and start sniffing

    Select the PlayStation, Xbox, smartphone, or other local device you want to monitor, then click Start Sniffing.
